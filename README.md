## QuantLibAddIn/Python

The QuantLibAddIn Python Wrapper provides a Python interface to QuantLibAddIn, exposing the functionality of the QuantLib C++ analytics library through an object-oriented API that close mirrors the architecture used by Excel-based QuantLibXL.

It enables Python developers to access QuantLibAddIn's analytics, pricing engines, market data structures, and financial instruments while retaining the object-oriented conventions and workflow familiar to QuantLibXL users.

- [PyPI](https://pypi.org/project/quantlib-addin/) – Python package distribution and installation.

---

The Python bindings are generated by parsing the QuantLibAddIn C++ library and cross-referencing its function signatures and parameters with the corresponding definitions in ObjectHandler and QuantLibAddin. This approach ensures that the Python interface accurately reflects the underlying C++ API, including function signatures, parameter types, and object relationships.

[bindings/QuantLibAddinCpp.cpp](https://github.com/mkipnis/QuantLibAddInPython/blob/master/bindings/QuantLibAddinCpp.cpp) - Auto-generated Python bindings for the QuantLibAddin C++ library.

### qlAddinCalculate

The `qlAddinCalculate` function accepts an instrument `ObjectId` and an optional dictionary of calculation parameters. Using registered instrument handlers, it identifies the underlying object type, performs the appropriate C++ upcasting to the corresponding QuantLibAddin instrument class, and dispatches the requested calculation. The function returns the calculation results as a Python dictionary, providing a consistent interface for accessing instrument-specific analytics, cashflows, sensitivities, and other available results.

* [qlAddinCalculate](https://github.com/mkipnis/QuantLibAddInPython/blob/main/qlap/qlap.hpp) - Declaration of the `qlAddinCalculate` function.
* [register_handlers.cpp](https://github.com/mkipnis/QuantLibAddInPython/blob/main/qlap/register_handlers.cpp) – Instrument handler registration and type mapping.
* [instrument_handlers.cpp](https://github.com/mkipnis/QuantLibAddInPython/blob/main/qlap/instrument_handlers.cpp) – Instrument type resolution, upcasting, and calculation dispatch.

##### Example: Bond Pricer 
[bond.py](https://github.com/mkipnis/QuantLibAddInPython/blob/main/examples/bond.py)

```
#  Price to Yield
price_to_yield_setup = {'price':105.015625}
price_to_yield = qla.qlAddinCalculate(fixed_rate_bond, price_to_yield_setup)
results = price_to_yield["results"]
print(f"Price: {results['cleanPrice']} -> Yield: {results['yield']}")

# Yield to Price
yield_to_price_setup = {'yield':0.05}
yield_to_price = qla.qlAddinCalculate(fixed_rate_bond, yield_to_price_setup)
results = yield_to_price["results"]
print(f"Yield: {results['yield']} -> Price: {results['cleanPrice']}")
```

## Building Python Wheel 

### Linux
```
python3 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install --upgrade build scikit-build-core pybind11 ninja

python -m build --wheel --no-isolation --verbose
python -m pip install dist/*.whl --force-reinstall
```

### Windows
```
py -m venv .venv
.venv\Scripts\activate.bat

python -m pip install --upgrade pip
python -m pip install --upgrade build scikit-build-core pybind11 ninja

$env:CMAKE_ARGS = "-DBOOST_ROOT=C:/boost -DBoost_ROOT=C:/boost -DBoost_INCLUDE_DIR=C:/boost/include -DBoost_LIBRARY_DIR_RELEASE=C:/boost/lib"

python -m build --wheel --no-isolation --verbose
python -m pip install .\dist\quantlib_addin-0.1.0-cp313-cp313-win_amd64.whl --force-reinstall
```
